# US-001: Browse material options by category

## User Story

As a Client, I want to see the material categories and the options in each, so that I can compare visual directions.

- **Type:** happy-path
- **Covers:** FR-material-library-002, 003, 004

When the client opens Material Library and selects "Characters"
Then MATERIAL CATEGORIES lists each category with its count and Characters is highlighted
