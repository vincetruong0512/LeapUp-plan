# US-001: Sign in with my User ID

## User Story

As a Client, I want to sign in with the User ID and password Leap Up gave me, so that I can reach my project workspace.

## Context

Login screen as on board 01 (L18–L170). Accounts are issued by Leap Up only (BR-auth-access-001). Error wording is TBD.
Revised 2026-11-22 after the MVP review (QA-17, QA-18, QA-20, SBA-24).

- **Type:** happy-path
