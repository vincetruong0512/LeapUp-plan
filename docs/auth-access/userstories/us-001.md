# US-001: Sign in with my User ID

## User Story

As a Client, I want to sign in with the User ID and password Leap Up gave me, so that I can reach my project workspace.

## Context

Login screen as on board 01 (L18–L170). Accounts are issued by Leap Up only (BR-auth-access-001). Error wording is TBD.

### AC-001 — Successful sign-in

- **Type:** happy-path
- **Covers:** FR-auth-access-001, 007
- **Screen:** login

```gherkin
Given an active account with User ID "nguyen.an" assigned to project "711"
When the user enters that User ID and the correct password and presses "Sign In"
Then the user is signed in and sees the landing page (TBD) with project "711"
```

### AC-002 — User ID is not case-sensitive

- **Type:** business-rule
- **Covers:** FR-auth-access-005 / BR-auth-access-003
- **Screen:** login

```gherkin
Given an account with User ID "nguyen.an"
When the user signs in with "Nguyen.An" and the correct password
Then the sign-in succeeds
```

### AC-003 — Wrong credentials

- **Type:** error-path
- **Covers:** FR-auth-access-004
- **Screen:** login-error
- **Error code:** E-auth-access-001

```gherkin
Given any User ID and a password that do not match an account
When the user presses "Sign In"
Then the user stays on Login
And E-auth-access-001 is shown (wording TBD)
```

### AC-004 — Empty field

- **Type:** error-path
- **Covers:** FR-auth-access-003
- **Screen:** login-error
- **Error code:** E-auth-access-002

```gherkin
Given User ID or Password is empty
When the user presses "Sign In"
Then no credentials are checked
And E-auth-access-002 is shown (wording TBD)
```

### AC-005 — Show password

- **Type:** happy-path
- **Covers:** FR-auth-access-002
- **Screen:** login

```gherkin
Given a typed password is masked
When the user presses "Show"
Then the typed password is readable
```
