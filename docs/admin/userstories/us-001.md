# US-001: Create a project

## User Story

As a Admin, I want to create a project for a client, so that Leap Up and the client have one place for that production.

## Context

Quote P1 #1. No board design (C3): screens TBD. Project details shown on the board: name, client, due date, description, status "In Progress" (L16–L24).
