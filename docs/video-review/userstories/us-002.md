# US-002: Pin a comment to a timecode

## User Story

As a Client, I want to add a comment at the exact moment of the video, so that Leap Up knows exactly what to change.

## Context

"Add comment at 00:15..." (L147); markers (L57–L59); quote §1 "review video theo từng giây".

- **Type:** happy-path
- **Covers:** FR-video-review-005, 007, 008 / BR-video-review-001, 002

