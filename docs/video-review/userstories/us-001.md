# US-001: Watch a round's video online

## User Story

As a Client, I want to play the current round's video in the browser, so that I can review it without downloading.

## Context

Board 07 player (L56–L145).

### AC-001 — Play video

- **Type:** happy-path
- **Covers:** FR-video-review-004
- **Screen:** video-review

```gherkin
Given round 2 has video "711_FILM_R2_V02.mp4"
When the client opens Video Review
Then the file name "711_FILM_R2_V02.mp4" is shown above the player
When the client presses play
Then the video plays in the page and current/total time is shown
When the client presses pause
Then the video stops at the current position
When the client uses volume and fullscreen
Then the volume changes and the player fills the screen
```

### AC-001b — Header and sidebar

- **Type:** happy-path
- **Covers:** FR-video-review-001, 002
- **Screen:** video-review

```gherkin
Given project "711" round 2 is open in Video Review
Then the breadcrumb reads "Projects / 711 / Outcome Development / Video Review"
And the title "Video Review" and the round pill "Round 2" are shown
And the sidebar shows Dashboard, Projects, Files, Outcome Review with Outcome Review active
```

### AC-002 — Playback fails

- **Type:** error-path
- **Covers:** FR-video-review-015
- **Screen:** video-review-error
- **Error code:** E-video-review-002

```gherkin
Scenario Outline: playback fails

When the client <action>

Examples:
  | failure                        | action          |
  | cannot be loaded               | presses play    |

```

### AC-002b — Retry after failure

- **Type:** error-path recovery
- **Covers:** FR-video-review-015

```gherkin
Given E-video-review-002 is shown and the video can be loaded again
When the client chooses Retry
Then the video plays
```
