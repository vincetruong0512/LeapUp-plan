# US-001: See a project's folders and files

## User Story

As a Client, I want to see my project's folders and files with their status, so that I know what Leap Up has shared and where it stands.

## Context

### AC-001 — Project screen as on board

- **Type:** happy-path
- **Covers:** FR-project-files-001, 002, 004, 005
- **Screen:** project-files

```gherkin
Given a member opens project "711"
When the Project Files tab is shown
Then the header shows name, status, client and due date
And three folder cards Proposal, Material, Outcome Development are shown
And the file table shows Name, Folder, Last Modified, Uploaded By, Status
```

### AC-002 — Status values

- **Type:** business-rule
- **Covers:** FR-project-files-009 / BR-project-files-003
- **Screen:** project-files

```gherkin
Scenario Outline: status shown
  Given a file with status "<status>"
  When the table is shown
  Then its Status column reads "<status>"

Examples:
  | status    |
  | Shared    |
  | In Review |
  | Approved  |
  | Final     |
```

Who sets a status, and whether Approved / Final are Phase 1 labels: **blocked by spec OQ-5, OQ-13**.

### AC-003 — Other project's files hidden

- **Type:** permission
- **Covers:** FR-project-files-013
- **Screen:** not-assigned (auth-access)
- **Error code:** E-auth-access-003

```gherkin
Given client A is not a member of "Grab Transport"

Then no file of "Grab Transport" is listed
And E-auth-access-003 is shown (wording TBD)
```

File download, video and comment cases: see auth-access US-002 AC-002 (one AC per surface).

### AC-004 — Phone browser

- **Type:** non-functional · **blocked by spec OQ-9** (phone layout) and review D-06 (test devices)
